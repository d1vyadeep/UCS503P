# Week 2: Authentication Screens and Navigation

## Objective
Create the initial account screens and the main navigation flow.

## Contributions
- Implemented or refined the login and registration interface in React.
- Added form fields for email and password, with name and role fields for registration.
- Connected the form actions to Supabase authentication methods for sign-in and sign-up.
- Added user-facing feedback for failed authentication and email-confirmation requirements.
- Reviewed the page layout to keep labels, controls, and error messages easy to identify.

## Technologies Used
- React: authentication components and form state.
- JavaScript: submit handlers and conditional rendering.
- Supabase Auth: account creation and sign-in.
- CSS: layout and responsive presentation.
