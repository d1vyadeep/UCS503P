# Week 1: Frontend Setup and UI Planning

## Objective
Set up the frontend workspace and plan the user interface for the adaptive reading companion.

## Contributions
- Reviewed the project requirements and identified the main user flow: login/register, reading space, reading preferences, and saved content.
- Reviewed the existing visual reference and identified reusable design elements such as the brand mark, cards, buttons, typography, and calm page colors.
- Set up and reviewed the React application structure using Vite.
- Planned reusable UI components and consistent styles for forms, panels, buttons, and settings.
- Considered readability in the design, including clear labels, sufficient spacing, visible focus states, and uncluttered layouts.

## Technologies Used
- React: component-based interface.
- JavaScript: interaction and state handling.
- CSS/Tailwind CSS: layout, typography, and responsive styling.
- Vite: frontend development server and build tooling.
- Figma (design planning): wireframes and screen-flow planning, if used by the team.

## Challenges and Learning
The main design challenge was keeping the interface calm and simple while still exposing useful reading controls. I planned to prioritize the reading area and avoid presenting too many actions at once.

## Next Steps
Build the authentication screens and connect navigation between the main application views.
